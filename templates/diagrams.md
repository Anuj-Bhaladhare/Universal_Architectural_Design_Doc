# Diagrams

## Recommended Diagrams
- System context (C4 Level 1)
- Container diagram (C4 Level 2)
- Component diagram (selected services)
- Sequence diagrams for critical flows
- Entity-relationship diagram
- Deployment diagram

## Tools
- Mermaid, PlantUML, draw.io, Excalidraw, etc.

## Storage
Store source files (`.mmd`, `.puml`, images) in this folder or link them from architecture docs.

## Naming
`YYYYMMDD-description.ext`
