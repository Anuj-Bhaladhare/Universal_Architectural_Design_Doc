# Contributing

Thank you for contributing to Project Design Docs.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change.
3. Improve templates, examples, checklists, or documentation structure.
4. Keep Markdown consistent and readable.
5. Open a pull request with a clear description of the change.

## Guidelines

- Prefer clear, actionable templates over long prose.
- Keep examples realistic and technology-agnostic where possible.
- Update the main README if you add new sections.
