# Pre-Development Checklist

Use this before starting implementation.

## Requirements
- [ ] Goals and non-goals defined
- [ ] User stories / use cases written
- [ ] Functional & non-functional requirements captured
- [ ] Success metrics agreed

## Architecture
- [ ] System context understood
- [ ] Major components identified
- [ ] Key ADRs recorded (or planned)
- [ ] Frontend / backend architecture sketched

## API & Data
- [ ] API style and conventions chosen
- [ ] Core endpoints or schema outlined
- [ ] Data model drafted
- [ ] Indexes and key queries considered

## Security
- [ ] Authn / authz approach decided
- [ ] Threats and mitigations noted
- [ ] Secrets and encryption approach defined

## Delivery
- [ ] Environments defined
- [ ] CI/CD approach agreed
- [ ] Testing strategy outlined
- [ ] Monitoring / observability plan exists

## Documentation
- [ ] Docs structure created
- [ ] Templates filled or linked
- [ ] Diagrams drafted or planned
